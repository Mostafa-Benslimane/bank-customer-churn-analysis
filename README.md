# Bank Customer Churn Analysis

Goal: To determine which factors contribute the most to customer churn in a bank.

Description: This dataset contains information on 10,000 customers related to a specific bank (age, geography, customer activity status, etc.), where I aimed to determine which attributes affect customer churn the most.

Skills: Data cleaning/modeling, data analysis, data visualization.

Technology: Excel, MySQL Workbench, Power BI.

Results: Using SQL queries, I identified a pattern showing that the older the customer, the higher the likelihood of leaving the bank. Additionally, customers from Germany have nearly double the churn rate compared to others, and inactive customers are more likely to churn than active ones. In conclusion, these three factors represent the main drivers of customer churn.
